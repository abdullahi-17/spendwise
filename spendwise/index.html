01 Problem

Make space to reflect before a purchase.

SpendWise explores whether a short check in can help someone notice their mood, planning, and sense of urgency while considering a purchase. This is a design question, not a demonstrated reduction in spending or regret.

User need being explored

A simple way to pause, reflect, and make a choice without being judged or prevented from continuing.

Engineering challenge

Deliver a small application with explainable API responses, graceful fallback, scoped deployment access, and a reviewable recovery process.

02 Opportunity

Keep the product small and the engineering visible.

The demo focuses on one complete reflection flow. Its cloud implementation uses API Gateway and a Python Lambda function, with matching rules in the browser when the API is unavailable. GitHub Actions checks and packages the website before deployment.

The portfolio distinguishes application tests from cloud evidence. Live API integration, alert delivery, and rollback still need a hosted demonstration. No verified market-size estimate or competitor comparison is claimed here.

03 The solution

A moment to pause before a purchase.

The working browser demo asks three questions, offers an optional pause and written reflection, then presents a neutral insight. The mobile studies below illustrate a broader future concept; they are separate from the implemented demo.

Notice the moment

Start a reflection manually with a clearly labelled sample item. Shopping-app detection is not connected to this demo.

Make room to reflect

Answer a few questions about mood, planning, and urgency. Take an optional pause and consider a brief, non-judgemental reflection.

Choose with intention

Choose to continue shopping, consider the item later, or dismiss it. The outcome is simulated; nothing is purchased, reserved, or saved as history.

The aim is greater confidence and awareness, not to block purchases or make financial decisions for someone.
